WorkoutTracker - REST API
WorkoutTracker is a Spring Boot application designed as a practical tool for tracking workouts and managing user profiles.

This project serves for learning core Spring Boot concepts, building clean backend architecture, and implementing end-to-end API security.

Project Goals
Master the Spring Boot framework and apply backend best practices in a real-world project

Build a clean RESTful API for users and workout data

Model relational data and database mappings with PostgreSQL

Implement secure authentication and authorization using Spring Security and JWT

Protect sensitive data and encrypt passwords using BCrypt

Set up clean, centralized exception handling across the application

Tech Stack
Java, Spring Boot, Spring Data JPA, PostgreSQL, Lombok / SLF4J, Maven
